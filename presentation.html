🔒 嚴謹的安全驗證機制

  • X-Line-Signature 驗證：每次 Webhook 請求均即時比對 HMAC-SHA256 簽章，防止假冒攻擊。
  • 金鑰環境隔離：.env 與 .gitignore 隔離機密，絕不將 Secret 提交至版本庫。

⚡ 高效非同步處理引擎

  • ASGI 架構：基於 FastAPI 與 Uvicorn，具備高併發承載與毫秒級快速回應能力。
  • 自動化 API 文件：內建 OpenAPI (Swagger UI)，利於維護、監控與健康度檢測。

04. 核心功能與指令模組

豐富實用的交談式互動指令設計與事件監聽

BOT FEATURES

💬 1. 智慧回音與導引 (Echo Engine)

當使用者傳送日常對話時，機器人會即時回傳輸入內容，並在訊息末端主動提示可用指令選單，提升使用者互動黏著度。

📅 2. 即時系統日期查詢 (/date)

整合 Python datetime 模組，即時讀取伺服器當前日期與時間，告別舊版程式硬編碼（Hardcoded）日期的缺陷。

⏱️ 3. 參數化倒數計時器 (/countdown)

支援自訂秒數（例如 /countdown 5），將倒數過程與結果格式化為文字序列回傳，重現並升級原 hello.py 倒數概念。

🎴 4. 結構化 Flex Message (/card)

採用 LINE 官方 Flex Message 格式封裝 JSON 卡片，展示結構化系統資訊與功能檢查標記，打破傳統純文字單調視覺。

🤝 好友生命週期管理 (FollowEvent)

當新用戶掃描 QR Code 或搜尋 ID 加入好友時，系統將自動捕捉加入事件，並第一時間推送熱情迎賓詞與全指令操作指南。

🛡️ 機敏資料脫敏實務 (Secrets Protection)

在現代雲端開發中，金鑰外洩是重大資安危機。本專案嚴格落實脫敏策略：

  • .env.example：提供公開範本檔，指引開發者欄位設定。
  • .gitignore：強制將 .env、快取與虛擬環境排除在 Git 之外。
  • 事前驗證：透過 git check-ignore 檢驗確保金鑰永不上雲。
